Gestures

Apple Pencil

  • Draw
  • Open the contextual tool palette from Tools, the floating chip, or T
  • Safari does not receive native Pencil Pro squeeze or hardware double-tap
  • Lasso with the Lasso tool
  • Tap to select
  • Drag a selection to move
  • Corner handles to resize
  • Scribble with Object erase

Finger

  • One finger = Pan
  • Two fingers = Pan / Pinch Zoom
  • Two-finger tap = Undo
  • Three-finger tap = Redo

Keyboard

  • ⌘Z = Undo
  • ⌘⇧Z = Redo
  • ⌘C = Copy
  • ⌘V = Paste
  • ⌘D = Duplicate
  • Delete = Delete
  • ⌘A = Select All
  • T = Pencil tools
  • Escape = Close palette / Deselect
